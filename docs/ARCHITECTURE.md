# 实现结构与策略

```text
WinForms 界面
    ↓ 仅本机的带令牌 HTTP 请求
Python 服务 → 单线程 QuickJS 控制器
    ↓                         ↓
CDP → 网易云主页面         内存音频工作进程
    ↓                         ↓
读取实际队列与控制播放     Media Foundation 解码
                              ↓
                          NumPy 分析节拍和能量
                              ↓
                          Rubber Band 保音高变速
                              ↓
                          WASAPI 过渡播放
                              ↓
                    静音预跑、尾段淡出与原音量渐变交接
```

## 源码入口

| 路径 | 职责 |
| --- | --- |
| `src/desktop/Automix.cs` | 窗口、托盘、启动与退出、依赖解压校验、网易云连接、自检。 |
| `src/automix/lite_server.py` | 本机 HTTP 服务、状态展示与任务监督。 |
| `src/automix/lite_controller.py` / `lite-shims.js` | 把共享控制脚本接入单线程 QuickJS 与 Python 原生能力。 |
| `src/automix/automix-memory.mjs` | 队列检查、准备音源、触发交接、静音预跑、渐变与恢复逻辑。 |
| `src/automix/frontend-probe.js` | 检查已加载的网易云主页面模块，提供队列、进度、播放控制与控制权保护。 |
| `src/automix/memory_mix_worker.py` | 仅通过内存接收音源，分析、混音与播放过渡。 |
| `src/automix/handoff_envelope.py` | 尾段平滑增益和瞬态诊断。 |
| `src/automix/memory_measure.py` | 可选的内存回环测量；音频在测量后清理。 |
| `src/native` | Windows 内存解码适配器与 QuickJS 宿主。 |

## 过渡选择

播放器绑定按完整客户端版本选择。目前分别适配 `3.1.40.205461` 与 `3.1.41.205564` 的已加载模块；后者的进度由客户端原有读取函数取得，并校验播放实例，避免把上一首残留进度用于当前歌曲。未适配构建会阻止控制。音源仍走客户端正常音质、权限和试听策略，不加载未知模块，也不分发客户端代码。

当前只有节拍混音与普通淡入淡出两条主要路径。节拍混音会检查 BPM 比值与节拍网格强度，以小范围保音高变速完成对拍；条件不足时采用普通淡入淡出。普通曲线按交接窗内两首歌的短时 RMS 轻微移动，接近静音时保留默认等功率曲线。峰值保护作用于外部混音片段。

下一首由网易云实际队列的选择器确定。切歌、心动模式队列变化、暂停、调音量、控制器失去控制权或超时都可能使当前计划失效。恢复逻辑会检查当前播放实例与用户操作，以免误覆盖用户后续的选择。

## 音量交接

过渡片段末尾含 600 毫秒平滑淡出以及 80 毫秒零尾段。下一首先在网易云静音预跑，音量渐变比外部片段淡出提前 130 毫秒启动，容纳控制命令和调度的延迟。`handoffSchedule.completionLeadMilliseconds` 记录音量命令相对外部尾段归零的完成余量；它不是直接测得的扬声器延迟。

两路流没有逐采样共同调度，B 的位置误差、声卡处理和歌曲本身动态仍可能影响听感。程序的相关性、峰值与静音检测只是诊断指标，不作为所有歌曲都完全无缝的保证。

## 数据与边界

常规流程不保存音乐文件，也不建立用于绕过网易云播放权限的资源库。源音频、PCM 与回环测量在内存中处理并尽力清理；日志包含歌名与运行状态。播放器页面与本地服务分别限于本机，HTTP 控制接口校验 Host、Origin 和会话令牌，CDP 目标校验主页面与本机地址。

该版本没有提供人声分离、云端歌曲特征库、完整段落分析或与 Android 客户端相同的全部策略。设计背景和代码来源关系见 [第三方说明](../THIRD_PARTY_NOTICES.md)。
